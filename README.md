# SpendWise 💸
*A 3-tier web application designed to track transactions, parse bank statements, and provide data-driven budgeting insights.*

## 📌 Project Overview
SpendWise helps students and young professionals overcome the hassle of manual financial tracking. By allowing users to upload standard bank statement files (CSV), the system automatically validates, extracts, categorizes, and visualizes income, expenses, and savings goals securely.

## 🗂️ Repository Structure
- `docs/` — Contains Part I (Requirements Specification) and Part II (System Design) documents and reports.
- `presentations/` — Slide decks and presentation assets for class evaluations.
- `backend/` — REST API server, database models, and CSV parsing engine.
- `frontend/` — Interactive React/Next.js dashboard and UI components.
- `sample_data/` — Sample bank statement CSV datasets (`bankstatements.csv`) used for testing and demo dashboards.

## 🚀 Key Features
* **Secure Authentication:** User registration and role-based access control.
* **Statement Upload & Parsing:** Automated extraction of date, description, amount, and debit/credit fields from CSV files.
* **Smart Categorization:** Rule-based tagging of transactions into food, transport, utilities, and more.
* **Interactive Dashboard:** Dynamic charts showing spending trends, net cash flow, and category breakdowns.
* **Savings Goals:** Set target amounts and track progress over time.

## 🛠️ Tech Stack
* **Frontend:** React.js / Next.js, Tailwind CSS, Recharts
* **Backend:** Node.js, Express (or Python, FastAPI)
* **Database:** PostgreSQL
* **Version Control:** Git & GitHub
